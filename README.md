## Overview

This repository contains the **logical design** (not source code) of a system that helps Community Health Workers (CHWs) in rural Sierra Leone:

- Register patient cases and symptoms  
- Calculate urgency level (Green / Yellow / Red) using decision rules  
- Generate referral advice to the nearest Peripheral Health Unit (PHU)  
- View pending referrals and update case status  

The design uses computational thinking, algorithms, pseudocode, modular design, decision structures, and repetition structures as required by the PROG101 assignment.

**No source code is included** – only the logical solution.

## Open Source & Digital Public Goods

The logical design is intended to be **open source** so that:

- Local developers and students in Sierra Leone can adapt it  
- It can be translated into local languages (Krio, Mende, Temne, etc.)  
- Other low-resource health systems can reuse the decision logic  

It is designed to meet the criteria of a **Digital Public Good** (open, accessible, and for public benefit).
